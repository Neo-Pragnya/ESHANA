ESHANA: one JSON entry point, three thin shells

Every surface calls Engine::execute_json, so the CLI, the Python package and the HTML report cannot disagree.

The numbered steps
#From → toWhat happens
1Request (JSON) → eshana-timeA request names an instant (UTC, or civil time plus zone) and the settings used
2eshana-time → eshana-ephemerisThe instant becomes TT and UT time scales and Julian dates
3eshana-ephemeris → eshana-engineA provider returns apparent ecliptic positions in one frame
4eshana-engine → Envelope (JSON)Rule packs derive signs, houses, nakshatra, dasha and gates; each value is labelled
5Envelope (JSON) → eshana CLIThe CLI prints the envelope as JSON
6Envelope (JSON) → eshana (Python)Python returns the same data as a dict or a Chart
7Envelope (JSON) → eshana-reportThe report renderer turns the envelope into one self-contained HTML file

Compute, Derive, Interpret: the engine stops after Derive
